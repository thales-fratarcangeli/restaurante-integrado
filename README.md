# RestaurantePRO — gestão completa de restaurante

![HTML](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white) ![CSS](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black) ![Chart.js](https://img.shields.io/badge/Chart.js-FF6384?logo=chartdotjs&logoColor=white)

Sistema web de gerenciamento de restaurante que integra salão, caixa, cozinha,
delivery, estoque e financeiro em uma única interface — feito em **HTML, CSS e
JavaScript puros**, sem framework e sem etapa de build.

**🔗 Demo:** https://thales-fratarcangeli.github.io/restaurante-integrado/

## Módulos

| Módulo | O que faz |
|---|---|
| **Dashboard** | Receita dos últimos 7 dias, vendas por categoria, pedidos recentes, top produtos e alertas |
| **PDV** | Venda no caixa com busca e filtro por categoria, comanda, quantidades e formas de pagamento |
| **Pedidos** | Quadro Kanban com o status de cada pedido em tempo real |
| **Mesas** | Mapa do salão com 24 mesas, detalhes da ocupação e reservas do dia |
| **Cardápio** | Produtos, categorias e preços |
| **Entregas** | Delivery com status e mapa dos entregadores |
| **Clientes** | Base de clientes e programa de fidelidade |
| **Estoque** | Ingredientes e insumos, com entrada de estoque |
| **Financeiro** | Fluxo de caixa, DRE simplificado, lançamentos e contas a pagar |
| **Relatórios** | Vendas dos últimos 30 dias, formas de pagamento e vendas por hora |
| **Configurações** | Dados do restaurante, usuários e permissões, fiscal, integrações e impressoras |

## Stack

HTML5 · CSS3 · JavaScript (vanilla) · Chart.js · Font Awesome

## Rodando localmente

Não precisa instalar nada: basta abrir o `index.html` no navegador.

```
index.html   estrutura das telas
style.css    layout responsivo e tema
app.js       navegação, PDV, Kanban, mesas, gráficos e dados de exemplo
```

> Os dados são de demonstração e ficam em memória — ainda não há backend.
